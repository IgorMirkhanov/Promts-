# Генератор каруселей

ТЗ из контент-плана → готовые PNG-слайды 1080×1350 (4:5) + подпись к посту.

## Быстрый старт

1. Установи [Node.js 20+](https://nodejs.org).
2. Запусти `start.cmd` (Windows) или `./start.sh` (Mac/Linux). При первом запуске установятся зависимости и откроется `.env`.
3. Впиши в `.env` ключи (см. ниже), сохрани, запусти снова.
4. Откроется http://localhost:3000. Вставь ТЗ, нажми «Сгенерировать», скачай слайды и скопируй подпись.

Для вёрстки нужен браузер: подхватится установленный Chrome или Edge (Edge есть в любой Windows).

## Ключи (`.env`)

| Переменная | Что это | Без неё |
|---|---|---|
| `LLM_API_KEY` | Ключ нейросети для текста. По умолчанию DeepSeek (`platform.deepseek.com`). Для OpenAI/OpenRouter поменяй `LLM_BASE_URL` и `LLM_MODEL`. | Работают только готовые JSON-ТЗ с уже написанными текстами |
| `IMAGE_API_KEY` | Ключ генерации фонов (OpenAI Images, `gpt-image-1`) | Фоны — градиенты в цветах бренда |
| `BRAND_NAME`, `BRAND_COLORS` | Бренд по умолчанию, если в ТЗ не указан | Тёмно-синий + оранжевый |

## Как устроено

```
ТЗ (текст или JSON)
 ├─[0] Разбор ТЗ        prompts/brief-parser.md  → 00_brief.json
 ├─[1] Копирайтер       prompts/copywriter.md    → 01_copy.json
 ├─[2] Проверка         src/steps/qa.ts (правила) + prompts/qa.md, правки prompts/revise.md (до 2 раундов) → 03_qa.json
 ├─[3] Арт-директор     prompts/art-director.md  → 02_art.json
 ├─[4] Фоны             src/images.ts            → backgrounds/
 └─[5] Вёрстка          src/render.ts            → slides/slide_01.png…, caption.txt
```

- Текст на картинку **не** рисует нейросеть: она делает только фон, а текст накладывается шаблоном. Поэтому в кириллице нет ошибок, а стиль одинаковый на всех слайдах.
- Проверка запрещает ссылки, @-упоминания, «телеграм/тг/t.me» и обещания гарантий в слайдах и подписи, а также следит за лимитами слов.
- Каждый шаг сохраняется в `output/<пост>/`. Правка текста в интерфейсе перерисовывает слайды без повторных запросов к нейросети. Галочка «пересоздать с нуля» генерирует всё заново. При изменении ТЗ пост пересоздаётся автоматически.
- Если фон для какого-то слайда не сгенерировался, пост всё равно соберётся: на этом слайде будет градиент, а в логе появится предупреждение.

## ТЗ

Свободным текстом, как в `briefs/example-text.txt`:

```
Тема: …
Аудитория: …
Цель: переход в канал. Кодовое слово в комментариях — ЧЕКЛИСТ
Слайд 1 (обложка): …
Слайд 2 (боль): …
Слайд 3 (польза): …
Слайд 7 (призыв): …
```

Или строгим JSON, как в `briefs/example.json`. Интенты: `hook` (обложка), `problem` (боль), `story` (история/кейс), `value` (польза), `bridge` (подводка), `cta` (призыв).

Механика призыва:
- `comment_keyword`: «Напиши в комментах СЛОВО — пришлю в директ» (ссылку присылает автоответ в директ);
- `link_in_bio`: «Полная версия — по ссылке в шапке профиля».

## Командная строка (для пачки постов)

```bash
npm run carousel -- briefs/post.txt       # один пост
npm run carousel -- briefs/               # все ТЗ из папки
npm run carousel -- briefs/post.txt --force
```
