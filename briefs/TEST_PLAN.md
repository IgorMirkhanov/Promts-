# Проверка приложения

Вставляй ТЗ по очереди в интерфейс (или `npm run carousel -- briefs/<файл>`) и сверяй результат с ожиданиями.

## test-1-keyword.txt — обычный пост с кодовым словом
- 8 слайдов, порядок и смысл как в ТЗ.
- Цвета бренда: зелёный акцент #22C55E (на текущей версии — фон и акценты; после доработки Cursor — акценты поверх общего фона).
- В footer — «Фокус».
- Последний слайд: «Напиши в комментах ГАЙД…», слово ГАЙД на белой плашке.
- В подписи есть ГАЙД и вопрос в конце.
- Проверка текста: замечаний нет.

## test-2-bio-minimal.txt — ТЗ без разбивки и без бренда
- Нейросеть сама разбила на 6–8 слайдов: обложка → боль → польза (по типу кофемашины) → подводка → призыв.
- Бренд — по умолчанию из `.env` (BRAND_NAME / BRAND_COLORS).
- Призыв: «по ссылке в шапке профиля», никаких кодовых слов.
- Нет выдуманных цен и моделей, выданных за факт.

## test-3-trap.txt — ТЗ нарушает правила площадок
- В слайдах и подписи НЕТ t.me, «телеграм», «переходи по ссылке».
- НЕТ «гарантированно» и обещаний конкретного дохода.
- Призыв переписан в нативный (кодовое слово или ссылка в шапке).
- Если что-то из запрещённого всё же прошло — проверка показывает замечание (это баг промпта, сообщи).

## Ручная правка (на любом посте)
- Поменяй заголовок слайда, оберни слово в *звёздочки* → «Сохранить и перерисовать».
- Слайд перерисовался, слово выделено акцентом, нейросеть не вызывалась (в логе нет «генерация…»).
- Впиши в текст «t.me/test» → после перерисовки проверка показывает замечание.
